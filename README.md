# Configurações Básicas para Controle
Bem vindo ao tutorial para configurações básicas da área de controle da EDRA.

Aqui faremos toda a instação desde o sistema operacional utilizado até a simulação das missões. 

Todos os passos necessários para começar estão descritos aqui, na primeira parte: **INSTALAÇÃO**. 
Nela será feita a configuração de todo o ambiente do sistema operacional para podermos enfim, simularmos.

Após essa etapa inicial, rodaremos uma Missão Teste, a fim de conferirmos se tudo foi instalado corretamente! 
Todas as informações necessárias para essa etapa, estão descritas em: **MISSÃO_TESTE**.
